# Grammar Adventure — Grade 1 Learning Hub

A browser-based learning arcade by Ms. Samar Gomaa, featuring four educational games for Grade 1:

- Missing Letter Arcade
- Capital Letter Maze
- Singular and Plural (Noun Jewel Heist)
- Vocabulary Revision

## Run locally

Open `index.html` in a modern browser. For service-worker and install-app support, use a local static web server or deploy with HTTPS.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to finish publishing. The site URL should be `https://samar-g1-2026.github.io/A1/`.

The project is a static front-end website and does not require a backend or secrets.
