# Capital Letter Maze — V4

- **50-question bank** based on Proper Nouns, Days of the Week, Months of the Year, and Capital Letters.
- Every new game randomly selects **5 different questions** from the 50.
- Clicking **New Maze** creates a fresh maze and a fresh set of 5 questions.
- The maze uses a randomized perfect-maze generator and places all 5 checkpoints on a guaranteed route.
- Correct answers unlock checkpoints; wrong answers cost a life and provide a lesson hint.
- On-screen controls, Arrow Keys, and WASD.
- Kid-friendly cartoon design with English letters, stars, fox guide, score, lives, sound, pause and restart.
